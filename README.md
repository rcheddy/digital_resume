# Rachel Chidester — Career Portfolio v9

## What's included
A concise, static, mobile-responsive HTML resume website, printable/downloadable resume PDF and locally hosted personal photographs. No JavaScript or build tools needed.

## Changes from v8
- Removed all three synthetic demo pages, demo scripts and homepage demo links. Demonstrations can be refined separately later.
- Rewrote the three strengths to state practical outcomes rather than only duties.
- Replaced all three Section 3 photographs with the three most recent user-supplied photographs (rainforest walk, clinical neuromonitoring leads, team science).
- Strengthened clinical experience in the homepage, personal story and employment history without implying current licensure.
- Rewrote the contact section specifically for job opportunities, recruiters, hiring managers and networking.

## Free publishing with GitHub Pages
1. Create a new PUBLIC GitHub repository under Rachel’s own account.
2. Upload the **contents** of this folder to the repository root (index.html, styles.css, favicon.svg, assets/ and the resume PDF).
3. Open Settings > Pages, choose Deploy from a branch, choose main and / (root), then save.
4. Open the published URL and verify photo crops, downloads and contact links on desktop and phone.

No changes were made to any existing GitHub repository. Because this is a public portfolio, verify permission to publish photos depicting other people before deploying.
